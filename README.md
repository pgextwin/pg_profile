# pg_profile 4.16 for Windows x64

pgextwin packages [pg_profile](https://github.com/zubkov-andrei/pg_profile/tree/0e80bd0251cf1603b72504dc693f78382563495f) from the upstream 4.16 release for PostgreSQL 15–18. The extension collects PostgreSQL workload statistics over time and generates reports from those samples.

## Installation

1. Copy the ZIP's `share/extension/` files into the corresponding directory of your PostgreSQL installation. The ZIP includes the extension control file, the 4.16 installation SQL, and the 4.15-to-4.16 migration SQL generated by upstream's Makefile.
2. In the database that will store samples, run:

   ```sql
   CREATE EXTENSION IF NOT EXISTS plpgsql;
   CREATE EXTENSION IF NOT EXISTS dblink;
   CREATE EXTENSION pg_profile;
   ```

pg_profile is SQL-only. Its required extensions are `plpgsql` and `dblink`. The optional extensions `pg_stat_statements` and `pg_stat_kcache` provide additional statistics on monitored servers. pg_profile can reset statement statistics while sampling, which can affect other monitoring tools. Use a disposable PostgreSQL cluster for sample tests.
